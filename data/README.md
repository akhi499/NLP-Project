# Dataset placement

The project is configured for Mendeley Data DOI `10.17632/499w76zjn2.1` (CC BY 4.0). Put the extracted tabular file under `data/raw/`. The inspector accepts CSV, TSV, JSON, JSONL, XLSX, and Parquet. Use `python scripts/download_dataset.py` to try the public Mendeley ZIP endpoint, then extract the archive, or download via the dataset page and place the extracted file here. Raw files are git-ignored and never modified in place.
